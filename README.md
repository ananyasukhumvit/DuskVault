# DuskVault

DuskVault is a distributed, real-time data synchronization platform for secure cloud repository management and automatic, continuous backup.

DuskVault is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/DuskVault.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

DuskVault is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
